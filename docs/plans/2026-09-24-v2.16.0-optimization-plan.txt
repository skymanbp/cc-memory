用户要求：(1) 优化插件向 Claude 注入提示词/上下文的方式及其管理，提高运行效率；(2) 排查设计冲突，整体优化、瘦身；(3) 整体内容条理化、降低混乱；(4) **必须验证**每个项目的记忆库能被自动调用，且去重与垃圾记忆清理是强制且生效的。

## 方案

### 共享基础件（都放在既有模块，除 `core/prompts.py` 外不加模块）
- `hooks/_entry.py:spawn_detached(argv) -> bool`：`stop.py:491-504` 的 Popen 形状（DEVNULL×3、`close_fds=True`、Windows `DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP`、POSIX `start_new_session=True`），`except OSError: return False`；模块级 `import subprocess` 并通过模块属性调用（smoke:6627-6649 会 monkeypatch `subprocess.Popen` 并断言 `--cwd` argv）；追加在文件末尾（:1675-1819 四个锚在 `parse_payload`/`resolve_project` 内）。`_maybe_kick_consolidation` 改用它，签名与 argv 不变。
- `hooks/consolidate_async.py:_acquire_lock(lock_path, stale_s=_STALE_LOCK_S)`：加关键字参数，默认不变（smoke:1347-1348 两参调用不变）；`.observer.lock`、`.retro.lock` 复用它（60 s 过期）→ 锁策略仍只有一个点（directive:863-871）。
- `core/auth.py`（只 import `json/os/time/pathlib`，每回合路径已经懒 import 它）：`llm_backoff(state_dir) -> (active, info)`、`note_llm_failure(state_dir, reason)`、`clear_llm_backoff(state_dir)`；文件 `.ccm/.llm_backoff.json = {"until", "failures", "reason"[:200], "ts"}`，延迟 `min(60·2^(failures-1), 1800)` s，缺失/损坏视为不激活，成功即 unlink，用 `core.atomic.write_atomic` 写。
- `.ccm/` 新增 `.observer.lock`、`.retro.lock`、`.llm_backoff.json`：三份 gitignore 列表同序追加在 `.consolidation.kick` 之后 + ARCHITECTURE §7 树（两种语言）。
- **`core/prompts.py`（新模块，"提示词管理"的落点）**：只放 Claude 可见文本的常量与占位符模板——握手 reminder 模板、`RESUME_TRIGGERS`（合并 `session_start.py:501-502` / `user_prompt.py:402-405` / `core/recall.py:171-175` 三份）、`<cc-memory-recall>` 帧标签与前言、PROGRESS.md/MEMORY.md/PLAN.md 头尾文案、主题回退摘要前缀 `FALLBACK_SUMMARY_PREFIX`；**不做渲染、不调用 neutralize**（`tools/contracts.py` 的 `render_paths` 集合不变）；`ACK_*` 仍留在 `core/progress.py`（r15ackspell 要求只在那里拼）。登记：`SUBPACKAGE_FILES["core"]`、`build_exe.py`、ARCHITECTURE §8 FLAT 图（两种语言，重签）。`/cc-mem inject-show --templates` 列出每个模板名与字节数。

### WP-A 运行效率：LLM 后台化与每回合开销（D2）

**A1 Stop 观察者 → 分离 worker（`stop.py --observe <cwd> <session_id>`）**
- `main()` 开头（`parse_payload()` :530 之前，与 `consolidate_async.py:179-185` 同形）：`if sys.argv[1:2] == ["--observe"]: _observe_worker(...); sys.exit(0)`。
- `continuation = bool(data.get("stop_hook_active"))`；`.exists()` 检查（:560）后**只构造一次** `MemoryDB`（删 :578-579 的第二次）。
- `if not continuation:` → `_maybe_spawn_observer(cwd, session_id, memory_dir, db, project_id)`（替换 :565 的内联调用）→ `maybe_run_idle(..., db=db)` → tag/patch(:584-585) → kick(:590)。Job-4 块(:603-669) 缩进不动，只把 `db.bump_plan_turn_counter(project_id, n=1)`(:630) 包进 `if not continuation:`。
- `_maybe_spawn_observer`（无 LLM、不读标记，按此顺序，保证无凭据的测试永不 spawn）：`get_api_key()` 空 → False；`observer_watermark` + `get_observations_since(..., limit=_MIN_OBS_FOR_EVAL)` 不足 3 条 → False；`llm_backoff` 激活 → False；`.observer.lock` 年轻于 `_OBSERVER_STALE_LOCK_S = 60.0`（名字不能是 `_STALE_LOCK_S`）→ False；否则 `spawn_detached([sys.executable, __file__, "--observe", cwd, session_id])`。不需要 kick 式冷却：失败 worker 写退避，崩溃 worker 的锁 60 s 过期。
- `_observe_worker`：`resolve_project` → `memory_dir` → `_acquire_lock(memory_dir/".observer.lock", stale_s=60)` → 锁内再查退避 → `_observer_evaluate(cwd, session_id, memory_dir, db=MemoryDB(db_path))` → `finally` 释放 → 一律 `sys.exit(0)`，整体 `try/except Exception: _log.error_tb`。
- `_observer_evaluate(..., db=None)`：保留主体与 `deadline=_HOOK_T0 + _LLM_DEADLINE_S` 字面；except 元组加 `RuntimeError` 并在其中 `note_llm_failure(memory_dir, str(e))`（`call_llm` 把每条腿的失败聚合成一个 `RuntimeError`——这才是"中断"信号；`extract_json` 为 None 只是坏答案，不写退避）；成功 `advance_observer_watermark` 后 `clear_llm_backoff`。水位仍只在成功 upsert 后前进。
- 提示标记竞态是已接受的残余（worker 在 Stop 后 ~100 ms 读 `cc_mem_prompt_`，子进程继承环境所以 `marker_dir()` 一致）；无新标记前缀。
- 牵连：smoke:2344-2384（字面与常量不变即过，加注释说明 deadline 现在约束的是 worker）；smoke:6624-6649（kick 的签名与 `--cwd` argv 形状要活）；directive §8(:684-735)、§9c(:822-872，真 spawn)；surfaces §4/§7/junk-cwd（无 key 不 spawn）；docs：CONTRACTS.md:225/zh:201 引 `stop.py:384`（`--fix`）、ARCHITECTURE.md:234/zh:212 Stop 行、README.md:739、`stop.py:5-7` docstring。

### drive2.py — 进程内驱动一个 hook：统计 sqlite3.connect 次数、打开+关闭耗时、进程内耗时、stdout 字节

```python
import sys, io, runpy, sqlite3, time
hook, payload = sys.argv[1], open(sys.argv[2], encoding='utf-8').read()
stats = {'n':0, 't_open':0.0, 't_close':0.0}
class TimedConn(sqlite3.Connection):
    def close(self):
        t=time.perf_counter(); r=super().close(); stats['t_close']+=time.perf_counter()-t; return r
orig = sqlite3.connect
def counting(*a, **k):
    k.setdefault('factory', TimedConn); t=time.perf_counter(); c = orig(*a, **k); stats['t_open']+=time.perf_counter()-t; stats['n']+=1; return c
sqlite3.connect = counting
sys.stdin = io.TextIOWrapper(io.BytesIO(payload.encode('utf-8')), encoding='utf-8')
real_out = sys.stdout; buf = io.BytesIO(); sys.stdout = io.TextIOWrapper(buf, encoding='utf-8', write_through=True)
t = time.perf_counter()
try: runpy.run_path(hook, run_name='__main__')
except SystemExit: pass
dt = time.perf_counter() - t
try: sys.stdout.flush()
except Exception: pass
out = buf.getvalue().decode('utf-8','replace'); sys.stdout = real_out
print(f"{hook.split('/')[-1]:<18} connects={stats['n']:>3} open+close={1000*(stats['t_open']+stats['t_close']):6.1f}ms  in-process={1000*dt:6.1f}ms  stdout={len(out):>6} chars")
if '--show' in sys.argv: print(out)
```
